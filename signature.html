  1. Host this folder first (images load from ).
  2. Click Copy signature.
  3. Gmail → Settings → See all settings → General → Signature → Create new → paste → Save changes at the bottom.
  4. If Gmail still shows only plain text: delete it, then drag over the preview above with your mouse, press Ctrl+C (⌘C), and paste again with Ctrl+V. Don't use Ctrl+Shift+V, which pastes plain text.
